<details>
<summary><b>⚙️ Setup guide (delete this block once you're done)</b></summary>

### 1. Create the special repo
Create a **public** repository named exactly `Saad-programmer` (same as your username), tick "Add a README", and paste this file in as `README.md`.

### 2. Find & replace
- `Saad-programmer` → your GitHub username
- `Your Name`, `you@example.com`, links, location, bio → your own

### 3. Enable the contribution snake (dynamic, animated)
Create `.github/workflows/snake.yml`:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches: [main]
permissions:
  contents: write
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
Run it once from the **Actions** tab. It publishes the SVGs to an `output` branch.

### 4. (Optional) Auto-updating blog posts
Create `.github/workflows/blog.yml`:

```yaml
name: Latest Blog Posts
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
permissions:
  contents: write
jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: gautamkrishnar/blog-post-workflow@v1
        with:
          feed_list: "https://dev.to/feed/YOUR_DEVTO"
          max_post_count: 5
```

### 5. (Optional) WakaTime weekly stats
Sign up at wakatime.com, add `WAKATIME_API_KEY` and a `GH_TOKEN` to repo secrets, then use the `athul/waka-readme` action.

### 6. Private contributions
In your profile, enable **"Private contributions"** under the contribution graph settings so the stats count them. Add `count_private=true` (already included).

### 7. Self-host stats (recommended)
The public `github-readme-stats` instance can hit rate limits. For rock-solid stats, deploy your own copy to Vercel and swap the domain in the URLs.

</details>
